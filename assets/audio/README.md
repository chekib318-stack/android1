# ملفات الصوت الموحدة

ضع هنا ملفات MP3 مسماة بمعرّف التمرين بالضبط، مثال:
- ex_001.mp3  (يقابل تمرين ex_001 في lib/data/sample_content.dart)
- ex_002.mp3
- ...

أي تمرين ما عندوش ملف هنا، التطبيق يستعمل صوت الهاتف الافتراضي (TTS)
تلقائيا كبديل احتياطي — بلا ما ينكسر أي شيء.

كيفية الحصول على الملفات:
1. تسجيل حقيقي بصوت بشري (الأدق والأنسب لتطبيق تربوي رسمي).
2. أو توليدها مرة واحدة عبر خدمة سحابية (Google Cloud TTS, Amazon Polly,
   ElevenLabs...) بصوت واحد ثابت تختاره، ثم حفظها هنا نهائيا.

بمجرد ما تحط الملفات، ما تحتاج تبدل أي كود — التطبيق يكتشفها تلقائيا.
